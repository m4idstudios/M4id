## Reporting a Vulnerability

Please report vulnerabilities privately through a
[GitHub security advisory](https://github.com/DoctorM4id/M4id/security/advisories/new)
rather than a public issue.

Include the M4id version, Minecraft version, and loader, plus steps to reproduce the stinker if you can.
